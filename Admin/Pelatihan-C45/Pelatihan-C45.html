Landasan Matematika C4.5

Integrasi Pengukuran Entropy Data

1. ENTROPY HIMPUNAN (S)

Entropy(S) = -Σ (Pᵢ × log₂(Pᵢ))

Mengukur ketidakmurnian atau heterogenitas kelas sasaran prioritas pemeliharaan.

2. INFORMATION GAIN

Gain(S, A) = Ent(S) - Σ (|Sᵢ|/|S| × Ent(Sᵢ))

Penurunan entropi setelah dataset dibagi berdasarkan atribut kandidat (A).

3. SPLIT INFORMATION

SplitInfo(S, A) = -Σ (|Sᵢ|/|S| × log₂(|Sᵢ|/|S|))

Proporsi informasi pemisahan cabang untuk menghindari bias atribut multivariat.

4. GAIN RATIO

GainRatio(S, A) = Gain(S, A) / SplitInfo(S, A)

Kriteria pemilihan simpul: Gain Ratio terbesar pada seluruh kandidat Root / Branch Node.
